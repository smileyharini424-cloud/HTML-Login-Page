# HTML Login Page

## Explanation

This project demonstrates how to create a simple login page using HTML. It uses HTML form elements to collect a username and password from the user.

## Problem Statement

Create a basic login page using HTML with fields for username and password, along with a login button.

## Features

* Username input field
* Password input field
* Remember me checkbox
* Login button
* Forgot password link
* Simple and beginner-friendly HTML structure

## How It Works

The `<form>` element is used to create the login form.

The `<input type="text">` element accepts the username.

The `<input type="password">` element accepts the password while hiding the entered characters.

A checkbox is provided for the "Remember me" option.

The submit button is used to submit the login form.

## Technologies Used

* HTML5

## Program Flow

1. Open the login page.
2. Enter the username.
3. Enter the password.
4. Select "Remember me" if required.
5. Click the Login button.
6. The form is submitted.

## Sample Input

Username: Harini
Password: 12345

## Sample Output

A login form containing username, password, Remember Me checkbox, and Login button is displayed.
